# Contributing

## Branching

- `main`: estable y lista para release.
- `develop`: integración continua del equipo.
- feature branches sugeridas: `feature/<scope>`

## Conventional Commits

Usar mensajes como:

- `feat(landing): add institutional hero`
- `fix(api): validate moodle token payload`
- `chore(docker): align nginx upstreams`
- `docs(readme): expand setup guide`

## Moodle policy

- No modificar el core.
- Personalizar solo mediante themes, plugins y configuración.
